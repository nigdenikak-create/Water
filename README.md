# Живой аквариум

Тест школьного экрана 8:3. На странице постоянно плавают 60 рыбок, нарисованных кодом. Интернет нужен только для первоначальной загрузки сайта.

Откройте index.html в браузере. Все файлы должны оставаться рядом: index.html, style.css, app.js, background.png.

F — полный экран. H — скрыть показатели. На школьном экране достаточно открыть ссылку: движение начинается автоматически, настройка количества не требуется.

Счётчик показывает текущий и средний FPS, средний интервал кадра и количество кадров дольше 33 мс. При изменении размера окна средние показатели сбрасываются. На экране 60 Гц ориентир плавности — около 60 FPS. Замер отражает частоту кадров браузера, а не задержку самой панели. Проверяйте непосредственно на школьном устройстве в течение нескольких минут.
